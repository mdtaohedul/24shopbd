# 24ShopBD React Store

## চালু করার নিয়ম
1. Node.js 18+ ইনস্টল করুন।
2. এই ফোল্ডারে Terminal খুলুন।
3. `npm install`
4. `npm run dev`
5. ব্রাউজারে Vite যে local URL দেখাবে সেটি খুলুন।

Production build: `npm run build`

## অ্যাডমিন
হেডারের অ্যাডমিন লিংক থেকে প্রবেশ করুন। ডেমো পাসওয়ার্ড: `admin1234`। পণ্য যোগ/সম্পাদনা/মুছুন এবং অর্ডার তালিকা দেখুন। ডেটা এই ব্রাউজারের localStorage-এ থাকে।

## গুরুত্বপূর্ণ
এটি React frontend prototype। বাস্তব ব্যবসায় প্রকাশের আগে নিরাপদ admin authentication, database, image storage এবং order API-র জন্য Supabase/Firebase বা নিজস্ব backend যুক্ত করতে হবে। বর্তমান ডেমো পাসওয়ার্ড production authentication নয়। bKash/Nagad অপশনটি placeholder; merchant integration যুক্ত করা হয়নি।
